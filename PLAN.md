# Aurora Confinement website plan

1. Set up a strict, static Next.js (App Router, static export) project in this repository with a minimal npm dependency set.
2. Build the shared mobile-first design system, accessible navigation, metadata, footer, and approved image handling.
3. Add every required public route, a Markdown news collection, and the print-friendly `/brief` page.
4. Add accessible contact and NFF forms with shared validation, honeypot protection, and an honest local demonstration adapter.
5. Add security headers, sitemap and robots routes, form/deployment documentation, and the missing-content register.
6. Run formatting, TypeScript checks, validation tests, a production build, accessibility checks, and browser QA at all requested widths; fix issues found.

No deployment or third-party service will be connected in this phase.
